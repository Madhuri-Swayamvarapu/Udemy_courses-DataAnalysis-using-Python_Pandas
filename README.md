**Udemy Courses Data Analysis 📊**

This project focuses on analyzing Udemy courses data using Python Pandas in Jupyter Notebook.
The dataset was explored to understand course subjects, pricing, subscribers, publishing trends, and top-selling courses.

**🔹 Tools & Libraries Used**

Python

Pandas

Jupyter Notebook

**🔹 Key Operations Performed**

✦ Importing & Exploration

✦ Data Filtering & Sorting

✦ GroupBy Analysis

 ✦ String Matching

✦ Datetime Conversion


**🔹 Project Questions Solved**

○ Subject with maximum courses

○ Free & Paid courses analysis

○ Top & Least Selling courses

○ Graphic Design courses below 100 price

○ Python related courses

○ Courses published in 2015

○ Maximum subscribers for each level

**🔹 Learning Outcome**

Improved understanding of Pandas Data Analysis techniques such as filtering, grouping, sorting, and handling datetime data for real-world datasets.
